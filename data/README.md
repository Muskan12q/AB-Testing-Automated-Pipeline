# Dataset

This project uses the Marketing A/B Testing dataset from Kaggle.

The dataset contains user-level information about an advertising campaign, including:

- User ID
- Test group
- Conversion status
- Total ads shown
- Most ads day
- Most ads hour

The original CSV file is not included in this repository because of its large file size.

To run the project, place the dataset in this folder with the filename:

`marketing_ab.csv`
